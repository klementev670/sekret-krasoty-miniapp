# Мини-апп — каталог и оформление заказа

Статические файлы: `index.html`, `style.css`, `app.js`. Обращаются не к сайту
напрямую, а к прокси-серверу бота (`bot/webapp_server.py`) — так секретный
API-ключ не попадает в код, который загружается в браузер пользователя.

## Что уже сделано
- Каталог товаров с поиском (через API, не только по загруженным) и подгрузкой
  "Показать ещё" (в каталоге может быть больше 50 товаров — столько отдаёт
  один запрос максимум)
- Карточка товара (фото, цена, наличие, описание, кнопка "в корзину")
- Товары не в наличии в каталоге не показываются
- Корзина с изменением количества, сохраняется между заходами (`localStorage`)
- Форма оформления заказа (имя, телефон, email, адрес) → создаёт заказ через прокси
- После успешного заказа шлёт событие боту через `Telegram.WebApp.sendData`

## Единственное, что нужно подставить
В `app.js`:
```js
const PROXY_BASE_URL = "https://ВАШ-ДОМЕН-ИЛИ-ТУННЕЛЬ/api";
```
Это адрес, по которому будет доступен прокси из `bot/webapp_server.py` —
см. README бота, раздел "Прокси для мини-аппа".

## Как опубликовать саму мини-аппу (варианты, любой рабочий)
1. **Тот же домен, что и сайт** — попросить программиста выложить папку `/miniapp`
   по любому пути на их хостинге, например `секреты-красоты.рф/miniapp/`
2. **GitHub Pages** — бесплатно: залить папку в репозиторий, включить Pages в настройках
3. **Netlify / Vercel** — бесплатный тариф, перетащить папку в интерфейс — https-ссылка за минуту

Главное требование — **https**, без него Telegram не даст открыть WebApp
(это касается и самой мини-аппы, и прокси, к которому она обращается).

## Как подключить к боту
1. Опубликовать прокси (см. README бота) и мини-аппу, вписать адрес прокси в `app.js`
2. Ссылку на опубликованную мини-аппу вставить в `.env` бота как `MINIAPP_URL`
3. Дополнительно (не обязательно): зарегистрировать мини-апп через
   [@BotFather](https://t.me/BotFather) → `/newapp`, тогда кнопка каталога сможет
   открываться и через меню бота, а не только через инлайн-кнопку
